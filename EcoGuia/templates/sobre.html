📖 Sobre el proyecto

Conoce la idea detrás de EcoGuía y por qué fue creado.

🎯

¿Cuál es el objetivo?

EcoGuía nació como proyecto de graduación con el objetivo de crear conciencia sobre el cambio climático a través de hábitos diarios concretos y medibles. La idea es simple: 30 días, 30 retos, 30 oportunidades de mejorar el planeta.

💻

¿Cómo está construido?

El proyecto está desarrollado con Flask y Python en el backend, usando plantillas Jinja para renderizar el HTML dinámicamente. El diseño está hecho con CSS puro, sin frameworks externos.

🚀

¿Qué viene a futuro?

A futuro se planea agregar un sistema de login para guardar el progreso de cada usuario en una base de datos, notificaciones diarias y un dashboard con estadísticas personales de impacto.

👤

Sobre el desarrollador

Proyecto desarrollado por un estudiante de Tarpon Springs High School como proyecto final de graduación en el área de desarrollo web con Python y Flask.

🌍 EcoGuía

Pequeñas acciones diarias, gran impacto para el planeta.
