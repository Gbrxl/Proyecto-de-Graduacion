# Proyecto-de-Graduacion
Este proyecto de graduación será para tener una guía de como contrarrestas las medidas del Cambio Climático.
## Esta es la idea de mi proyecto:
> Crear una app de retos sostenibles de 30 días que guíe a las personas a cambiar sus hábitos diarios con acciones concretas y medibles. Cada reto completado muestra el Co ahorrado, generando conciencia y motivación a través de logros y rachas, convirtiendo el cuidado del planeta en un hábito diario.
> El proyecto será una página web construida con Flask y Python, usando HTML, CSS y plantillas Jinja. 




🌍 EcoGuía

Este es mi proyecto de graduación de Tarpon Springs High School. Es una app web sobre el cambio climático donde puedes ver retos ambientales de 30 días, datos reales del planeta y un ranking de los usuarios más ecológicos.

Lo hice con Python y Flask porque quería aprender a hacer páginas web con un backend real, no solo HTML y CSS.


🔧 Con qué está hecho


Python 3
Flask
HTML y CSS (sin librerías, todo hecho a mano)
Jinja2 para los templates



 Páginas que tiene


Inicio — presentación del proyecto con estadísticas del cambio climático
Retos — 30 retos ambientales diarios
Datos Eco — cifras reales sobre el estado del planeta
Ranking — top 10 usuarios con podio y niveles
Sobre — de qué se trata el proyecto



 Cómo correrlo

pip install flask
python main.py

Luego abres http://127.0.0.1:5000 en el navegador.
